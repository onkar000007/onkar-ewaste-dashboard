ONKAR SHELKE — ASSIGNMENT HUB
================================
Open index.html in a browser to preview the dashboard.

This corrected build puts assignment files under assets/assignment-files and links to them using relative paths. Each available file has both View and Download links. Items named in Teams screenshots but absent from the uploaded source bundle are marked as missing rather than given fake links.

For Netlify:
1. Extract the ZIP.
2. Upload the entire extracted folder (the folder containing index.html and assets/) to Netlify.
3. Do not upload index.html alone; file access depends on the assets folder being deployed too.

Public deployment means visitors can access the files included in the public site. Review documents for private information before publishing.
